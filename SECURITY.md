# Security

## Scope

This repository is a static portfolio template. Security reports may concern
its source code, dependencies, configuration validation, generated content,
or deployment guidance. The current development branch is the maintenance
target; older snapshots have no stated support guarantee.

## Reporting a vulnerability

Do not disclose vulnerabilities, credentials, or personal data in public issues
or pull requests.

1. If this repository's GitHub **Security → Report a vulnerability** option is
   available, use it to submit a private report.
2. If private reporting is not enabled, use the repository owner's public
   profile contact details to request a private reporting channel. Send only
   a general description until a private channel is agreed.

Include the affected commit, environment, reproduction steps, expected impact,
and a minimal redacted example. Never send real credentials or personal data.
Private reporting availability and response times are not guaranteed here.

## Safe handling

- Test only installations you own or are authorized to assess.
- Avoid destructive tests and accessing other people's data.
- If a credential is exposed, revoke or rotate it with its provider; deleting
  it from the latest source alone is not sufficient.
- Coordinate disclosure with the maintainer before publishing exploit details.

For ordinary bugs and feature requests, use the issue templates instead.
