I'm Rusiru Rathmina, a Software Engineer at Omobio (Pvt) Ltd in Colombo, Sri Lanka — building and maintaining enterprise-grade applications for Dialog Axiata PLC, one of Sri Lanka's largest telecom providers.

My work spans the full lifecycle: PHP/Drupal backend systems, React frontends, AWS infrastructure, and container security with Docker and Kubernetes. I've led initiatives that reduced container image sizes by 60%, contributed to ISO 27001 compliance, and built OWASP-aligned secure development practices into production workflows.

Outside of enterprise work, I build developer tools and side projects — including MockDeck, an API mocking and integration testing platform, and I write about engineering on my personal blog.

I'm open to collaborating on full-stack, cloud, or DevOps projects. Let's build something reliable together.
