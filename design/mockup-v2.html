I'm Rusiru Rathmina — a Software Engineer at Omobio (Pvt) Ltd in Colombo, working on enterprise software for Dialog Axiata PLC, one of Sri Lanka's largest telecom providers.

My day-to-day spans Drupal and PHP backends, React frontends, AWS infrastructure, and container security. I've led efforts that cut container image sizes by 60%, contributed to ISO 27001 compliance programs, and built OWASP-aligned practices into production workflows used by millions of users.

Outside the enterprise work, I build developer tools — including MockDeck, an API mocking platform, and I write about engineering craft on my personal blog.

I'm open to collaborating on full-stack, cloud, or DevOps projects anywhere in the world.
