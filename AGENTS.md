# Architecture rules

- Personal facts, links, images, skills, certification URLs, and section order live in `src/config/site.json`; colors live in `src/config/theme.json` — keeps the site a reusable template.
- All user-visible wording (including section kickers, newspaper labels, Continuing Education entries, and skill domain notes) lives in `src/locales/<lang>.json` (auto-discovered) — new languages need no code changes.
- Visual design, typography (`Fraunces`, `Newsreader`, `IBM Plex Mono`), print rules, and layout must match [DESIGN.md](DESIGN.md), [SKILL.md](SKILL.md), and the canonical prototype at [docs/prototype/broadsheet-prototype.html](docs/prototype/broadsheet-prototype.html) — never reintroduce neon gradients, floating blur blobs, hero availability ears, or stat counter boxes (`2+`, `24`, `100%`).
- Media is served from `public/media/` and referenced by path in config — swapping images needs no imports.
- Social icons resolve via `src/components/icons/BrandIcons.tsx` keyed by platform id — config stays data-only.
- `scripts/site-files.ts` owns sitemap/robots/manifest/llms generation and HTML metadata/static fallback injection via `scripts/search-content.ts` — a shared input prevents visible/search content drift; never hand-edit outputs.
- Validate settings with `src/config/schema.ts` and locale dictionaries with `src/i18n/schema.ts` before runtime and generation; invalid section IDs/URLs must fail early instead of yielding broken links.
- Locale fallback merges each key and array position with English; translations retain English array order to keep content identities stable.
- Expandable section rows (`Experience` dispatches and `Projects` dossiers) use the shared Radix Collapsible wrapper (`src/components/DisclosureRow.tsx`) with support for single-row toggle, "Unfold All", and front-page jump-and-unfold actions; measured content height and separate outbound links prevent clipping and nested controls.
- Technical skills (`Skills.tsx`) present `siteConfig.skills` as an understated, adaptability-first horizontal domain ledger rather than a rigid tool-count grid.
- Formal education (`education.items`) and Continuing Education (`education.certifications`) render side-by-side in `Education.tsx`, driven by locale records and `siteConfig.educationLogos`.
- Navigation waits for lazy section targets and observes their insertion; mobile navigation uses a Radix modal to manage keyboard focus.
- Bun and the text `bun.lock` are authoritative; frozen installs prevent multiple package managers from drifting.
- Shared shadcn variant/helper exports and the brand icon registry are intentional lint Fast Refresh exemptions; keep other feature modules component-only.
- Each lazy section has its own loading state/error boundary; unused query/toast providers are not mounted on this static portfolio.
- Always use Conventional Commit messages (`feat:`, `fix:`, `docs:`, `style:`, `refactor:`, `test:`, `chore:`) when committing changes.
- Publication controls (including skill/social visibility) live only in `en.json` → `display`; a shared validated resolver derives runtime settings, keyed by stable locale record IDs; shared selectors preserve source indices for jumps and exclude unpublished entries from pages and search generation to prevent selection drift.
- Locale fallback never translates record IDs or English publication flags, because publication settings and jump targets require stable content identity across languages.
- Project affiliations use configurable locale label keys; never infer an employer or institution from project descriptions, because affiliation is owner-authored data.
